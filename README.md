
# Принцип работы
## Эффективный подсчет md5 для файлов при рекурсивном проходе директорий
Алгоритм должен работать эффективно при чтении с ssd и с hdd => используем пулл потоков в который раскидываем имена файлов
у нас будет 1 consumer (> 1 создаст много хаотичного доступа к памяти и замедлит чтение),
который через рекурсивный итератор из буста обходит директории и затем пушит в лок фри очередь moddycamel
